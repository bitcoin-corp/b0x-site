How it will work

Import. Host. Publish. Name.

1

Import

Connect Vercel or GitHub and pick a project. Static sites, docs and landing pages are the first target.

Deploy →

2

Host off chain Later

Hosting for previews and heavy media. Not built yet, and we haven't chosen the storage service. Today a site lives on chain.

Storage →

3

Publish on chain

Any version can be written to Bitcoin as a website ordinal: an ORDFS directory, each file its own inscription. bFriendsX and bVideoX already are.

Publish →

4

Name it

An OpNS name you own points at your latest version. Ship a new version, move the name.
