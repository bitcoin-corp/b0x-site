Today

On chain.

Each file an inscription

b0-x publishes a static site to Bitcoin SV. Each file is its own inscription, and an ORDFS directory maps paths to them.

Publishing →

Served by the gateway

The b0-x gateway serves published versions at b0-x.com/s/<name>/. bfriendsx and bvideox are there now. Subdomains like <name>.b0-x.com are planned; DNS isn't set up.

Permanent

A published version can't be edited or taken down. A new version gets a new directory, and the name points at it. Old versions stay.

Names point at versions

The gateway registry.

Each name points at one on-chain directory, its current version. These are the real entries today.

# name → current version (ORDFS directory)
bfriendsx  → v2  2f45c498…17c3_0
bvideox    → v3  ededbb57…30f1_0

Planned

Off-chain hosting. Not built

What it's for

Previews, and heavy media that shouldn't go on chain. Normal storage, not permanent.

Where it stands

Not built yet. We haven't chosen the storage service. No prices until it's real. The plan is to pay monthly from your wallet.

Anything you publish on chain won't depend on it.

Private files

That's bDriveX.

bDriveX is the bWalletX family's drive for private files. Files are encrypted on your device before upload; the server holds only ciphertext. You share with a link only the people you choose can open.

It's an invite-only beta, and there are no backups yet. It isn't web hosting: it can't serve a public website.

bStoreX, at bstorex.com, is the bWalletX store (themes and packs). It isn't storage.
