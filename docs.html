Getting started

You need bWalletX (web, Chrome extension or phone app) or another BRC-100 wallet, and a project whose build produces static files.

1. Sign in

$ npx b0-x login
→ Open bWalletX to approve sign-in for b0-x.com
✓ signed in as 03a1…9f2c

The CLI asks your wallet to sign a one-off challenge. No password, no API token to copy around.

2. Deploy

$ cd my-site
$ npx b0-x deploy            # builds, uploads, gives a preview URL
$ npx b0-x deploy --prod     # promote to production on bStoreX

3. Publish and name (optional)

$ npx b0-x publish           # inscribe this build as the next version
$ npx b0-x names point my-site latest

CLI reference Sketch

CommandWhat it does
b0-x loginSign in with bWalletX (BRC-100).
b0-x logoutForget the local session.
b0-x link [--vercel|--github]Link this folder to a Vercel project or GitHub repo.
b0-x deploy [--prod]Build and upload to bStoreX. Prints a preview URL, or updates production.
b0-x publish [--dry-run]Inscribe the current build as a new version. --dry-run prints files, sizes and cost without writing.
b0-x versionsList on-chain versions with their manifest outpoints.
b0-x names point <name> <version>Point an OpNS name you own at a version.
b0-x storage [ls|usage|pay]Inspect your bucket and pay for storage (lock or subscribe).

b0x.json Sketch

Optional. Without it, b0-x guesses from your framework.

{
  "name": "my-docs",
  "build": { "command": "pnpm build", "output": "out" },
  "hosting": { "bucket": "my-sites", "prefix": "my-docs/" },
  "publish": {
    "include": ["**/*"],
    "exclude": ["**/*.map", "drafts/**"],
    "maxSizeKB": 10000,
    "confirm": true
  },
  "name_service": { "opns": "my-docs", "follow": "latest" }
}

exclude matters most: anything published is permanent. Source maps, drafts and environment files should never be included, and .env* is always excluded whatever you set.

Limits

  • Static output only. API routes, serverless functions and databases stay on their current host.
  • Single-page apps need a fallback route; the config for that isn't designed yet.
  • Very large media is better kept on bStoreX than published.
