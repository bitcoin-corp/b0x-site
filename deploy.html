Deploy

From Vercel or GitHub
to Bitcoin.

Point b0-x at a project you already have. It builds the static output, uploads it to your bStoreX bucket and gives you a preview URL. Publishing on chain is a separate, deliberate step.

In development

Import

Two ways in.

You sign in with bWalletX, then link the source you already use. b0-x reads the project; it does not take it over. Your Vercel project and GitHub repo stay exactly where they are.

From Vercel

Link your Vercel account with a read-only token, pick a project, and b0-x pulls the build settings it can use: framework, output directory, build command.

From GitHub

Install the b0-x GitHub app on a repo. Pushes to the branch you choose trigger a build; other branches get previews.

From your machine

Or skip both: npx b0-x deploy in a folder uploads its built output directly.

Your key signs it

Every deploy is tied to your wallet key, so the dashboard, buckets and names all belong to you, not to an account we hold.

Build

Build, then upload the output.

b0-x runs your build command in a clean container and keeps only the static output: HTML, CSS, JS, images, fonts. That output is what gets hosted and, if you choose, published.

# illustrative
$ npx b0-x deploy
→ Detected: Next.js (static export) · output: out/
→ Running: pnpm build
→ 37 files · 4.2 MB
✓ preview at https://my-docs-git-feature-x.b0-x.app

Preview URLs

Every build gets its own URL on b0-x.app. Share it, check it, throw it away. Previews live in bStoreX only and are never written on chain.

Production

Promote a build to production and your custom domain or b0-x URL serves it from bStoreX.

Publish

Any build, preview or production, can be published on chain as a numbered version.

Honest scope

What works first, what comes later.

Nothing is live yet. This is the order we plan to build in.

  • FirstStatic sites: plain HTML, Vite, Astro, Next.js static export, docs generators (Docusaurus, VitePress, MkDocs). Upload, preview, production on bStoreX, publish on chain, OpNS names.
  • FirstSign-in and payment with bWalletX (BRC-100), so any BRC-100 wallet works.
  • LaterGitHub push-to-deploy and branch previews; Vercel project import with build-setting detection.
  • LaterCustom domains on hosted (bStoreX) versions.
  • Stays putServers, serverless functions and databases. A Next.js app with API routes keeps those on Vercel (or wherever it runs). b0-x hosts and publishes the static half: pages, assets, the front end.
